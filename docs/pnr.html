Phone Number Registration

How to register a phone number with OpenBubbles using an iPhone as a relay — written for how things actually work after Apple's October 2026 activation change.

About this guide

What this covers

This is meant to be an updated version of the OpenBubbles phone number registration page, kept current as the apps and relays change.

It covers registering a phone number with OpenBubbles yourself, using an iPhone you already have as the relay. It's free, and it needs a phone you can leave plugged in.

OpenBubbles also offers a paid hosted option, where they run the iPhone for you. If that's the route you'd rather take, it's described in their OpenBubbles Hosted write-up.

Unofficial

01Before you start

A few things first

On the Apple Account you'll register

  • Turn off Advanced Data Protection — Settings → your name → iCloud → Advanced Data Protection.
  • Turn off Contact Key Verification — Settings → your name → Contact Key Verification.

Both of these will block registration if they're left on, and the error you get won't say so.

On the iPhone acting as the relay

  • Sign out of any Apple Account on it, and turn off FaceTime and iMessage.
  • Leave it powered on and connected to Wi‑Fi or Ethernet. The relay has to keep running to keep the number registered.
02Method 1 · no jailbreak needed

Validation Relay+ on TrollStore

This method needs TrollStore, which covers iOS 14 through iOS 17.0. No jailbreak required.

Validation Relay+ is a fork of JJTech's ValidationRelay, updated for Apple's October 2026 change. It installs over the original and keeps its settings.

Setup

  1. Install TrollStore on the relay iPhone, if it isn't already.
  2. If TestFlight is installed, delete it. TrollStore needs its slot.
  3. Download ValidationRelay.tipa on the iPhone, or AirDrop it there.
  4. Open the .tipa with TrollStore and tap Install. On the home screen it shows up as Validation Relay+.
  5. Open it and leave Report as Mac on. A fresh install turns it on for you — that's what makes registration work now.
  6. Tap Copy Identity and paste it somewhere safe. More on why below.
  7. Turn Relay on. The screen shows a Registration Code that looks like this:
    K7MP-3RTD-9WQX-F4HN
  8. Enter that code in OpenBubbles. If you're switching from existing hardware, it's under Settings → Change Hardware.
  9. Back in Validation Relay+, turn on Keep Awake and use Dim Display. Leave the app in the foreground.

Report as Mac

Since October 2026 Apple refuses activations that look like they came from an iPhone, but accepts a Mac. Validation Relay+ generates a Mac identity and presents that instead. New installs have this on and need nothing from you.

If you're updating an install that's already registered and working (or recently working), it arrives off on purpose, so the update doesn't disturb what's working. Leave it off while it works. If you ever need to register from scratch, turn it on first and then tap Reset Registration Code.

Back up your identity

Apple activates each serial number once. If the app's identity is lost or regenerated, the registration made with it stops renewing and you have to register again. Copy Identity gives you the serial and UUID — keep them somewhere safe:

Serial: C02K7X9MDNCR
UUID: 9F3C1A42-7B55-4E0D-A1C8-62D4E7B09F11

Enter Identity puts a saved one back, which is how you move to a new phone or recover after a reinstall without re-registering.

There's also jakecrowley/ValidationRelay, a separate fork of the same app. It's worth knowing about, though it may not currently register successfully in all cases.

Optional, if you're jailbroken

None of these are required, and they may not be compatible with every iOS version.

  • AdvancedBrightnessSlider — dims further than iOS allows, which lowers burn-in risk on a screen that stays on.
  • ChargeLimiter — caps the charge level, which is kinder to a phone that lives on a cable.
  • Immortalizer — keeps the relay app alive with the screen off.
03Method 2 · jailbreak

relayserver, as a background service

On a jailbroken phone, relayserver runs as a background service instead of an app you keep open in the foreground. It covers iOS 14 and up, with both rootful (-arm) and rootless (-arm64) builds.

  1. Open Sileo — it comes with many jailbreaks, so there may benothing to install first. See https://jakecrowley.github.io/relayserver/

If your jailbreak uses Zebra or Cydia instead, add the same URL there. They all work the same way.

  • Install dev.copper.relayserver. Sileo picks the rootful or rootless build to match your jailbreak.

    If you'd rather install the .deb by hand, the builds are on the relayserver releases page.

  • It starts on its own once installed. Nothing to keep open, and it comes back after a reboot.
  • Read the registration code out of /var/mobile/config.json. Filza is the easy way to open it.
  • Enter that code in OpenBubbles. If you're switching from existing hardware, it's under Settings → Change Hardware.

    • If it isn't connecting, it logs to /var/mobile/relayserver.log.

    04If it doesn't take

    Common errors

    Registration failures usually come back as a numeric code from Apple. The useful ones:

    CodeWhat it meansWhat to do
    6001 Key data incompatible Advanced Data Protection or Contact Key Verification is still on. Turn both off, then try again.
    6005 Authentication rejected Often a temporary block after repeated attempts. Stop trying for a few hours.
    6009 Account temporarily disabled Apple has flagged the account. Appeal at apple.co/IMFT.
    6004 Try again Transient. Wait a bit and retry.
    5052 Number was just removed Give it some time before re-registering the same number.

    On Validation Relay+, also check that Report as Mac is on, then tap Reset Registration Code and enter the new code in OpenBubbles. Resetting also generates a new identity, so copy the old one first if you might want it back.

    Keep in mind that repeated failed attempts are what gets an account soft-banned. Change one thing, then wait.
